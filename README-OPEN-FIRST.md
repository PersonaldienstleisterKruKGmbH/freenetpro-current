# Freenet Pro — ready static site

Open **index.html** by double-clicking it. The complete site works directly from your computer; no PHP server, Node.js, VS Code, or Go Live extension is required.

All visible pages are static HTML. The project planner and contact forms keep their current email-app fallback, so a direct preview does not lose functionality. If a future version needs real server-side sending, file uploads, or saved submissions, that single function can be added as a separate PHP endpoint without changing the static page design.

For Hostinger, upload the whole contents of this folder into **public_html**. Before publishing, replace freenetpro.com in robots.txt, sitemap.xml, llms.txt, and llms-full.txt with the final domain if it differs.
